# ADR-023

Date  
2026-08-03

Track  
Track B (Dry Research)

## Question

Encapsulin-GNNにおいて、ADR-021で定義した edge feature の `ss_pair` をどのように表現するか。

ADR-021では DSSP由来二次構造を

```text
H
E
L
```

へ集約し、

```text
HH
EE
LL
HE
HL
EL
```

の6分類を採用した。

しかし実データ検証の結果、DSSPにおける

```text
T (Turn)
S (Bend)
P (Poly-Proline)
```

をLoopへ単純に統合すると、無視できない構造情報が失われる可能性が示された。

本ADRはADR-021の改訂版として位置付ける。

## Decision

ADR-021の `ss_pair` 定義を置き換える。

### Edge Definition

変更なし。

```text
Cα distance < threshold
```

thresholdはパラメータとして保持し、

初期値は

```text
8 Å
```

とする。

### Edge Features

#### actual_distance

```text
actual_distance
```

#### sequence_distance

```text
sequence_distance = |i - j|
```

#### ss_pair

DSSP由来二次構造を以下の4分類へ集約する。

```text
H = Helix

    H
    G
    I

E = Strand

    E
    B

L = Loop

    -

O = Other

    T
    S
    P
```

Edge featureとして以下の10分類を採用する。

```text
HH
EE
LL

HE
HL
EL

HO
EO
LO

OO
```

#### same_ss_element

```text
0 = different element
1 = same element
```

例

```text
Helix1 - Helix1 → 1
Helix1 - Helix2 → 0

Strand3 - Strand3 → 1
Strand3 - Strand7 → 0
```

## Rationale

ADR-021では

```text
H
E
L
```

への集約を採用した。

しかし実データ検証の結果、

```text
HO
EO
LO
OO
```

が無視できない頻度で出現することを確認した。

### 3DKT

```text
HO = 75
EO = 121
LO = 122
OO = 112
```

### 7S21

```text
HO = 76
EO = 67
LO = 191
OO = 112
```

### 9B9I

```text
HO = 73
EO = 91
LO = 153
OO = 129
```

これらの接触は局所構造形成や粒子曲率形成へ寄与している可能性があり、

```text
Turn
Bend
Poly-Proline
```

をLoopへ吸収してしまうことは情報損失につながると判断した。

一方で、

DSSPの全分類を直接利用するとカテゴリ数が過大になる。

そのため、

```text
H
E
L
O
```

の4分類へ集約し、

```text
10種のss_pair
```

を採用する。

## Alternatives Considered

### Alternative 1

ADR-021のまま

```text
HH
EE
LL
HE
HL
EL
```

を維持する。

**Rejected**

TurnやBend由来の接触をLoopへ吸収してしまう。

### Alternative 2

DSSP全カテゴリを利用する。

**Rejected**

カテゴリ数が増え過ぎ、

学習データ規模に対して過剰である。

### Alternative 3

```text
H
E
L
O
```

へ集約し、

10種のss_pairを構成する。

**Accepted**

情報保持と単純性のバランスが最も良い。

## Validation Results

Result-008において、

- threshold依存性評価
- sequence_distance評価
- same_ss_element評価
- HELO分類評価

を実施した。

HELO分類由来の

```text
HO
EO
LO
OO
```

接触が全対象構造で十分に観測されることを確認した。

したがって、

ADR-021のHEL版ss_pairは本ADRにより置換する。
