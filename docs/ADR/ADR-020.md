# ADR-020

## Date

2026-07-31

## Track

Track B (Dry Research)

---

## Question

PISA由来の界面特徴量をどのような粒度で保持するか。

候補として以下を検討した。

### Alternative 1

Global Feature のみ保持する

例：

- global_dASA
- total_interface_area

---

### Alternative 2

Partner-specific Feature のみ保持する

例：

- dASA_AB
- dASA_AC
- dASA_AF

---

### Alternative 3

Global Feature と Partner-specific Feature の両方を保持する

---

## Decision

PISA由来特徴量は、

### Global Feature

と

### Partner-specific Feature

の両方を保持する。

---

### Global Feature

粒子形成全体への寄与を表現する特徴量。

例：

- global_dASA
- interface_degree
- total_interface_area
- total_hbond_count
- total_salt_bridge_count

---

### Partner-specific Feature

各界面の寄与を表現する特徴量。

例：

- partner_chain
- dASA
- interface_area
- hbond_count
- salt_bridge_count

```text
Residue × Partner Chain
