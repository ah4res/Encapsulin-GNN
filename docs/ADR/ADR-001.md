# ADR-001

Date
2026-07-27

Track
A: Infrastructure

Question

研究の意思決定と結果をどのように管理するか

Decision

Research Operating System（Research OS）を採用する

Rationale

- チャット履歴は長期的に参照しにくい
- 研究の意思決定履歴を失いたくない
- Dry研究とWet研究を統合管理したい
- AIとの壁打ち結果を研究資産として蓄積したい

Alternatives Considered

- チャット履歴のみ利用
- 実験ノートのみ利用
- 個人記憶に依存

Status
 -Accepted
