# ADR-021

Date  
2026-08-02

Track  
Track B (Dry Research)

## Question

Encapsulin-GNNにおいて、Reference Chain A内部の残基間エッジをどのように定義し、どのエッジ特徴量を採用するか。

本ADRはADR-016で定義された局所グラフ表現の詳細設計として位置付ける。

## Decision

### Edge Definition

エッジは以下で定義する。

```text
Cα distance < threshold
```

thresholdは設定ファイルから変更可能なパラメータとして実装する。

初期値は

```text
8 Å
```

とする。

将来的なアブレーション試験として、

```text
4 Å
6 Å
8 Å
10 Å
```

を比較可能な設計とする。

### Edge Features

#### actual_distance

Cα-Cα実距離（Å）

```text
actual_distance
```

#### sequence_distance

残基番号差

```text
sequence_distance = |i - j|
```

#### ss_pair

DSSP由来の二次構造ペア

```text
HH
EE
LL
HE
HL
EL
```

として保持する。

#### same_ss_element

同一二次構造要素への所属を表すフラグ

```text
0 = different element
1 = same element
```

例：

```text
Helix1 - Helix1 → 1
Helix1 - Helix2 → 0

Strand3 - Strand3 → 1
Strand3 - Strand7 → 0
```

## Rationale

- 8 Åはタンパク質構造グラフにおいて広く利用される近接距離であり、局所構造表現に適している。
- thresholdを固定値とせずパラメータ化することで、後続の性能比較実験を容易にする。
- actual_distanceは空間的近接性を直接表現できる。
- sequence_distanceは局所接触と長距離フォールディング接触を区別するための情報を与える。
- ss_pairは二次構造間の関係性を表現する。
- same_ss_elementは同一ヘリックス内接触とヘリックス間接触、同一ストランド内接触とストランド間接触を区別できる。
- 正二十面体対称粒子では、サブユニットを構成する限られたfoldの配置様式および二次構造間相互作用が粒子形成に寄与する可能性があり、その情報をエッジ特徴量として保持する意義がある。

## Alternatives Considered

### Alternative 1

```text
Cα distance < 10 Å
```

のみを採用する。

**Rejected**

グラフが過密化し、局所接触と遠距離近接の区別が曖昧になる可能性がある。

### Alternative 2

```text
4 Å
6 Å
8 Å
10 Å
```

を別エッジ種として定義する。

**Rejected**

初期モデルとしては複雑性が高く、特徴量数増加による過学習リスクがある。

### Alternative 3

DistanceのRBF（Radial Basis Function）展開を採用する。

**Deferred**

有望な手法であるが、Baselineモデルではactual_distanceのみを採用し、必要に応じて後続ADRで導入を検討する。

### Alternative 4

edge_type（peptide bond / spatial contact）を採用する。

**Rejected**

sequence_distanceにより主鎖隣接性の情報を表現できるため、Baselineでは冗長と判断した。
