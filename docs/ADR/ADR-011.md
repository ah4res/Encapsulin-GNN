# ADR-011

Date: 2026-07-28

Track: Track B (Dry Research)

Question
==========

Icosahedral Particle Atlasにおいて、
T-numberをどのようなルールで決定するか。

当初の実装では、

T = Assembly Subunit Count / 60

による単純推定を採用した。

しかし検証の過程で、

- Thermotoga maritima encapsulin (3DKT)
- Rotavirus
- Reovirus
- 多層殻粒子
- 擬似対称粒子

などで誤判定または過大評価の可能性が確認された。

特に3DKTについては、

assembly_subunit_count = 120

から

T = 2

と推定されたが、

既知の生物学的知見とは整合しない可能性がある。

よって、

T-number決定手順を正式に定義する必要がある。

---

## Decision

T-numberは単純な

```text
subunit_count / 60
```

では決定しない。

以下の優先順位で決定する。

### Level 1

実験論文・構造タイトル・構造注釈に明示されたT-numberを採用する。

対象：

- Title
- Keywords
- Citation Title
- Metadata Annotation

例：

```text
T=1
T=3
T=4
T=13
```

Confidence

```text
1.0
```

Source

```text
title
metadata
citation
```

---

### Level 2

既知粒子データベースとの照合

対象例：

```text
Encapsulin
AAV
HBV
HK97
P22
MS2
PhiX174
Rotavirus
Norovirus
Calicivirus
```

文献によりT-numberが確立している場合は
文献値を採用する。

Confidence

```text
0.95
```

Source

```text
literature
curated
```

---

### Level 3

Biological Assemblyによる推定

Assembly Metadataから

```text
assembly_subunit_count
```

を取得し

```text
candidate_t =
assembly_subunit_count / 60
```

を計算する。

ただし次の条件を満たす場合のみ採用する。

```text
candidate_t が Caspar-Klug許容値
```

Confidence

```text
0.9
```

Source

```text
assembly
```

---

### Level 4

Unknown

信頼できる情報が存在しない場合は

```text
t_number = null
```

とする。

推測値を保存しない。

---

## Caspar-Klug Validation

Assemblyから推定されたT-number候補は
Caspar-Klug理論に適合する場合のみ採用する。

条件：

```text
T = h² + hk + k²
```

h,k は 0以上の整数。

許容例：

```text
1
3
4
7
9
12
13
16
19
21
25
27
28
36
39
...
```

不許可例：

```text
2
5
6
8
10
11
14
15
...
```

不許可値は

```text
caspar_klug_valid = false
```

として記録する。
