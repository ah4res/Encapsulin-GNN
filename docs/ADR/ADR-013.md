# ADR-013

Date: 2026-07-29

Track: Track B (Dry Research)

Question
==========

Icosahedral Particle Atlasから構築されるGNN学習データセットにおいて、

どの粒子を学習対象として採用するべきか。

ADR-011の検証過程において、

Thermotoga maritima encapsulin (3DKT)

が

```text
assembly_subunit_count = 120
↓
T = 2
```

と誤判定された。

調査の結果、

これは

```text
60 EncA shell protein

+

60 cargo protein
```

を同時に数えていたためであり、

T-number推定アルゴリズムの失敗ではなく、

学習対象粒子の定義が不十分であることが原因であると判明した。

また、

- Enterovirus
- Rhinovirus
- Poliovirus

などのPseudo-T粒子や、

- Rotavirus
- Reovirus

などの多層粒子では、

単純なサブユニット数による評価が困難である。

そのため、

GNN学習対象となる粒子の採用基準を定義する必要がある。

---

# Decision

GNN学習データセットには、

構造的解釈が容易であり、
T-numberの定義が明瞭な粒子のみを採用する。

学習対象は段階的に拡張するが、

初期段階では

```text
T=1

T=3
```

のみを対象とする。

また、

Pseudo-T粒子および複雑な多成分粒子は
当面除外する。

---

# Eligible Dataset

## Tier 1 (Gold Dataset)

対象

```text
T=1
```

かつ

```text
単一Shell Protein
```

または

```text
単一Major Capsid Protein
```

で構成される粒子。

例

```text
Encapsulin

AAV

Parvovirus

STNV

MS2

VLP
```

目的

```text
最初のGNN学習

特徴量探索

説明可能性検証
```

---

## Tier 2 (Silver Dataset)

対象

```text
T=3
```

かつ

```text
単一Major Capsid Protein
```

を持つ粒子。

例

```text
MS2

Calicivirus

Norovirus

植物ウイルス群
```

目的

```text
Hexamer形成原理

Quasi-equivalence

T=3粒子形成原理
```

の解析。

---

## Tier 3 (Future Dataset)

対象

```text
T=1 + T=3
```

の統合データセット。

目的

```text
T-number決定因子

粒子形成原理

Fold非依存特徴
```

の探索。

---

# Excluded Dataset

当面、

以下の粒子は学習対象から除外する。

---

## Pseudo-T Particle

例

```text
Poliovirus

Enterovirus

Rhinovirus

Coxsackievirus
```

理由

```text
複数Major Capsid Proteinを持つ

Pseudo-T構造を形成する

T-numberの解釈が複雑
```
