# ADR-015

Date
2026-07-30

Track
Track A (Infrastructure)

Question

GNN解析、CryoSPARC、Nanoporeシーケンス解析、
およびX線結晶構造解析を統合的に運用する
new-HPCをどのような構成で導入するか。

Decision

以下の構成を採用する。

- Vendor: リアルコンピューティング
- CPU: AMD EPYC 9254 (24 Core)
- GPU: NVIDIA RTX A5000 24GB ×2
- Memory: 64GB ECC
- System Storage: NVMe SSD 2TB
- Scratch Storage: NVMe SSD 8TB
- Data Storage: HDD 10TB
- OS: Rocky Linux 9
- Power: 100V
- CryoSPARC導入込み

将来的な要求増加に応じて、
メモリを128GB以上へ増設する。

研究データ保存は内蔵ストレージに依存せず、
外付けHDDによる運用を基本とする。

Rationale

- CryoSPARC、GNN、Nanopore解析はいずれもGPU依存度が高い。
- 予算内でGPU性能を最大化できる構成であった。
- RTX A5000はCryoSPARCで十分な実績がある。
- RTX A5000×2構成はGNNおよび将来的なAI活用にも有利である。
- メモリ価格が高騰しているため、初期導入は64GBとし、
  必要に応じて増設する方針とした。
- 100V運用でも本構成の消費電力に十分対応可能と判断した。
- ベンダーにCryoSPARC導入実績があり、
  学術用途への理解とサポート実績を評価した。

Alternatives Considered

1. コンカレントシステムズ案
   - CPU性能およびサポートは魅力的
   - しかしCryoSPARC導入実績とGPU構成の面で不利

2. メモリ128GB構成
   - 約50万円の追加費用が発生
   - 現時点の用途ではGPU増強を優先すると判断

3. 他社ワークステーション
   - ソフトウェア環境およびサポート体制に不確実性があった
