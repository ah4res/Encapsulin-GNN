# ADR-006

Date
2026-07-27

Track
A: Infrastructure

Question

AIツールをどのように使い分けるか

Decision

Copilot
- 壁打ち
- アイデア検討
- ADR作成支援

Cursor
- 実装
- Repository参照
- Current_State更新支援

Rationale

- CursorはRepository全体を参照可能
- Copilotは壁打ち能力が高い
- 現ライセンスではCopilot Agentに知識ベースを持たせにくい

Alternatives Considered

- Copilot中心
- Cursor中心

Status
- Accepted
