# ADR-014

Date: 2026-07-29

Track: Track C (Wet Research)

## Question

GNN解析結果を将来的に実験検証するため、

Thermotoga maritima Encapsulinおよび
Myxococcus xanthus EncAの

- 初期発現系
- コンストラクト
- 精製系
- 粒子形成評価系
- 熱安定性評価系

をどのように構築するか。  
また、変異体作製前に達成すべきWT評価項目を定義する。  
Result-004の文献調査結果を受けて決定する。

---

## Decision

初期Wet検証系として

- Thermotoga maritima Encapsulin (T=1)
- Myxococcus xanthus EncA (T=3)

を採用する。

変異体作製に先立ち、

- WT粒子形成
- 熱安定性
- Heat Challenge耐性

を評価する。

共通発現宿主は

```text
E. coli BL21(DE3) CodonPlus-RILP
```

とする。

# Rationale

Result-004の文献調査により、

Thermotoga maritima Encapsulinでは

- Tag-free
- His-tag

の両方で構造解析成功例が存在した。

一方、

構造上N末端は粒子内部を向き、
C末端は粒子表面に露出する。

そのため、

His-tagを利用する場合は

```text
C-terminal His6
```

を採用する。

また、

多数の変異体を評価する将来計画を考慮すると、

```text
硫安沈殿
↓
SEC
↓
DLS/TEM
```

を基本系とする方が高スループットである。

Myxococcus xanthusについては、

既報構造解析で

```text
N-terminal His-tag
```

が繰り返し使用されており、

同戦略を採用する。

# Alternatives Considered

## Alternative A

全コンストラクトをN-terminal His-tag化する

メリット

```text
精製容易
```

デメリット

```text
Tmではタグが粒子内部へ向く可能性
```

不採用

---

## Alternative B

Tag-freeのみ構築する

メリット

```text
天然状態に近い
```

デメリット

```text
精製トラブル時の保険が無い
```

不採用

---

## Alternative C

Tag-freeとHis-tagを並行整備する

メリット

```text
柔軟性が高い

リスク分散可能
```

採用
