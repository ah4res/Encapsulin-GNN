# ADR-010

Date: 2026-07-28

Track: Track B (Dry Research)

Question
==========

Encapsulin-GNNプロジェクトにおいて、解析対象データセットをどのように定義するか。

当初は対象をT=1 Encapsulin構造に限定していたが、粒子形成を規定する構造原理をより一般化して理解するためには、Encapsulin以外の正二十面体対称粒子も含めた解析基盤を構築すべきかが検討課題となった。

---

Decision
==========

解析対象データセットの管理基盤として、

**Icosahedral Particle Atlas**

を構築する。

本Atlasでは対象をEncapsulinに限定せず、

- Encapsulin
- Virus
- Virus-like Particle (VLP)
- Engineered Nanocage
- その他の正二十面体対称粒子

を収集対象とする。

収集条件は名称ではなく、

**正二十面体対称性（Icosahedral Symmetry）**

とする。

対象構造はPDBおよびEMDBから収集し、
将来的なGNN解析のための統一データセットとして管理する。

---

Rationale
==========

Project Charterでは、

> 正二十面体対称粒子形成を規定する構造原理の理解

を最終目標としている。

そのため本質的な解析対象は
「Encapsulinそのもの」ではなく、

**正二十面体対称粒子形成機構**

である。

Encapsulinのみを対象とした場合、

- 系統的多様性が小さい
- T-numberのバリエーションが限定される
- 一般化可能な粒子形成原理を抽出しにくい

という制約がある。

一方、

- Encapsulin
- Virus
- VLP
- Engineered Nanocage

を統合することで、

- 共通する粒子形成原理
- 対称性形成原理
- 曲率形成原理
- 界面構築原理

を横断的に比較可能となる。

また将来的なGNN学習においても、

- データ数増加
- クラス多様性向上
- 学習安定性向上

が期待できる。

---

Scope
==========

本ADRは

**データセット収集方針およびAtlas構築方針**

を定義する。

以下を対象とする。

### Data Source

- PDB
- EMDB

### Inclusion Criteria

以下のいずれかを満たす構造。

- Icosahedral symmetry
- Point Group I
- Icosahedral Biological Assembly
- Icosahedral EM Reconstruction

### Metadata

最低限以下を管理する。

- PDB ID
- EMDB ID
- Title
- Organism
- Resolution
- Experimental Method
- Particle Type
- Symmetry Group
- Point Group
- T-number
- Subunit Count

---

Out of Scope
==============

本ADRでは以下を定義しない。

- GNNアーキテクチャ選定
- ノード定義
- エッジ定義
- 特徴量定義
- Wet実験計画
- T-number推定アルゴリズム
- 幾何解析アルゴリズム

これらは別ADRで管理する。

---

Alternatives Considered
========================

### Alternative A

Encapsulinのみを対象とする。

メリット

- 実装が容易
- データ整理が簡単

デメリット

- データ数が少ない
- 汎化能力が低い
- 粒子形成原理の一般化が困難

不採用。

---

### Alternative B

Virusのみを対象とする。

メリット

- データ数が非常に多い

デメリット

- Project Charterとの整合性が低い
- Encapsulinとの比較ができない

不採用。

---

### Alternative C

正二十面体対称粒子全体を対象とする。

メリット

- Project Charterと整合
- データセット拡張性が高い
- 比較研究が可能
- 将来的なGNN解析に有利

採用。
